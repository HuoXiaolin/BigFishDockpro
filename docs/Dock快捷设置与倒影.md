# Dock 快捷设置与倒影

Dock 新增图标倒影、时间日期、九宫格和＋添加入口，默认开启。在「设置 → Dock 外观 → Dock 扩展」分别关闭。

![Dock 倒影与时间](screenshots/dock-reflections-clock.png)

快捷设置每页最多九个按钮。鼠标停在面板或按钮上，向下滚轮进入下一页，向上返回；也可点击底部箭头。

按钮提供任务栏效果与文字、外观与图标大小、应用管理、便签、时钟、日历等常用设置，按保存的顺序分页。组件开关沿用各自已保存的外观和位置；没有便签时首次开启会新建一张。

点击右上角「排序」，拖动按钮到目标位置即可交换；拖到翻页按钮并停留可跨页，也可右键选择移到上一页或下一页。「完成」退出排序，「重置」恢复默认顺序。顺序立即保存，保存失败时保留原排列。排序期间点击按钮不会误开关组件。

「切换外观」与主设置的「整体外观」共用主题，Dock、桌面卡片、便签、时钟和日历一起切换。经过清透水晶、液态玻璃、柔光流彩、活力原色、浅色纸玻璃、全透明后，选择「自定义」可恢复各组件各自保存的外观。图标大小和停靠位置也各有独立的自定义值。离开自定义时保存该项值，完整循环后返回；配置重载及重启后仍保留。自定义停靠保留距底部数值，不会改为默认距离；新的手动自定义会替换旧记录，其他设置不回滚。旧版已覆盖且未保留的自定义值无法自动找回，先在完整设置中重新保存一次即可。

Dock 的「轻透液态」预设现为高光36%、不透明度0%，其他选项保持该预设原有设置。已有自定义配置保留，可重新选择此预设应用。开启倒影时，图标底部到 Dock 底边的整段距离减半；图标尺寸保持不变。

＋入口仍调用已有多文件添加界面。

倒影在当前页图标加载时预合成，使用单张「图标＋倒影」代替原图绘制。动画帧不翻转图像、不生成渐变、不创建倒影缓存，也不增加每个图标的贴图调用次数。合成贴图预算为2 MiB，只保留当前页；贴图大小会按图标数量调整，关闭倒影会释放这些贴图。贴图绘制仍需要处理更多像素，不能把“不增加调用次数”理解为绝对零 CPU/GPU 成本。

时间按分钟刷新，隐藏 Dock 或关闭时间后停止时钟定时器。悬停动画按需运行，鼠标离开且动画结束后停止计时。

保存设置按实际变化更新对应模块；同一全局主题不反复应用，不因修改更新设置而重载全部应用图标、卡片与便签。没有改动时不重复保存。隔离样例的内存与耗时记录位于项目 artifacts，不代表所有电脑或真实桌面场景的性能验收。
