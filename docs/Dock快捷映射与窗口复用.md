# Dock 快捷映射与窗口复用

Dock 保存快捷入口引用，不复制、移动或备份应用、文档及文件夹。

## 快捷方式

固定 `.lnk` 时解析目标、启动参数、工作目录、图标位置及索引、窗口显示方式、管理员启动标志和已有的应用标识，写入配置中的入口。网页快捷方式保存其目标地址。普通文件和文件夹仍引用原路径。

删除桌面上的源快捷方式后，已经解析并保存的映射仍可使用。启动时会尝试迁移原有入口，保存失败保留原配置。已经丢失且旧配置从未保存目标的快捷方式无法反推目标，需要重新添加一次。删除原文件、移动目标或卸载应用仍会使对应入口失效。

图标设置可查看、修改目标、参数和工作目录。预览按控件实际尺寸及 DPI 等比居中显示，缺失的自定义图标优先回退到目标图标。

## 已有窗口

点击普通应用入口时按完整程序路径即时查找已有窗口，包含在 Dock 启动前就已打开的窗口，不依赖运行标记扫描或精简模式的后台轮询。优先恢复已有窗口；前台权限被 Windows 限制时提示现有窗口，不因此重复启动。

已有应用标识的 Chrome 等浏览器配置入口按窗口应用标识区分。明确要求打开网址、文件、新窗口、无痕窗口或管理员启动的参数保留原启动语义。应用标识不明的带参数入口也保留原启动方式。

相关接口依据：[Windows 前台窗口规则](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-setforegroundwindow)、[Shell 快捷方式](https://learn.microsoft.com/en-us/windows/win32/api/shobjidl_core/nn-shobjidl_core-ishelllinkw)、[Chromium 的窗口与快捷方式标识](https://github.com/chromium/chromium/blob/main/docs/windows_shortcut_and_taskbar_handling.md)。

## 默认和系统入口

新配置默认开启 Dock 图标拖动排序，原有明确关闭的配置保留。Windows 应用栏目补充网络、用户文件夹、桌面、下载、文档、图片、音乐和视频入口。界面沿用系统微软雅黑 UI，数值控件优先使用已安装的 Segoe UI 字体，不内嵌额外字体文件；用户已有的时钟字体设置保留。

验证使用独立 Windows 桌面、临时配置和真实原生测试窗口，覆盖启动前已有窗口、源快捷方式删除、参数和图标元数据、旧配置迁移、配置重载及导入导出。微信和 Chrome 的当前入口还做了只读窗口匹配检查；未操作其真实聊天或浏览内容，未在用户桌面做焦点切换测试。
