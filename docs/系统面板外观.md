# 系统面板外观

入口：总设置 → 外观与系统 → **开始菜单 / 通知面板**。保存后应用，默认关闭。无需安装 Windhawk，也无需向其他软件导入配置。

右键主托盘图标可切换开始菜单样式、外观来源和通知美化范围。「任务栏」子菜单提供自动文字配色、手动黑白字和外观设置。Dock 快捷设置也可循环切换开始菜单和通知面板的外观来源。

## 布局与位置

| 系统区域 | 外观与操作 |
| --- | --- |
| 开始菜单 · 系统默认 | 由 Windows 提供布局与外观。 |
| 开始菜单 · Windows 11 玻璃网格 | 左侧全部应用，右侧固定应用，底栏可打开原生搜索。电源和账户菜单使用同套材质和文字颜色。 |
| Windows 搜索 | 保留输入框、推荐内容、分类与匹配结果。隐藏快速搜索和热门应用，匹配结果使用单列。 |
| 快速设置 | 玻璃面板与圆角按钮，仍使用系统网络、蓝牙、音量等控件。 |
| 媒体控制 | 统一背景、圆角和封面边角，继续控制系统当前媒体会话。 |
| 通知与日历 | 统一通知列表、日历和通知弹窗外观，保留 Windows 通知内容与操作。 |
| 任务栏右键菜单 | 右键任务栏空白处时使用通知面板的材质和配色。保留系统菜单位置、任务管理器和任务栏设置。 |

点击系统开始按钮或按 Win 键仍在系统开始菜单位置弹出；Win+A、Win+N 和系统通知保留原来的右侧位置。程序不创建一个屏幕中央的替代面板，也不重设任务栏对齐方式。

点击开始菜单底栏设置齿轮左侧的放大镜即可进入 Windows 搜索。也可以从任务栏搜索入口或按 Win+S 打开。

开始菜单与搜索共用 563 × 625 逻辑像素的外框。搜索读取同一显示器上开始菜单的可见边界。直接按 Win+S 时，搜索在开始菜单坐标就绪前贴近系统任务栏。开始菜单展开期间，“自动调整”会根据实际背景亮度切换黑白文字，账户与电源子菜单沿用当前文字颜色。

底栏左侧是用户与电源，右侧是搜索与设置。鼠标打开账户或电源菜单时，Dock 在显示前核对各项的位置。点击区域错位时，菜单在触发按钮旁显示，背景取开始菜单当前底色，文字和图标沿用所选字色。开启 Windows 高对比度时使用系统菜单配色。选项、顺序和可用状态取自当前系统菜单。

应用列表占满左列，滚动条沿本列右缘显示。“全部”和字母分组与应用图标的左缘对齐。“已固定”标题居中对齐第一列图标。每行四张卡片，图标和名称在各自的点击区域内居中。搜索沿用开始菜单的位置、尺寸和圆角。

## 外观设置

- **跟随本应用**使用 Dock 混合后的底色、材质浓度和模糊强度。透明材质透出面板后方的颜色，浅色纸玻璃会在其上叠加与 Dock 相同的浅色底层。
- **跟随系统**：跟随 Windows 明暗与透明效果。
- **自定义**：分别设置开始菜单与通知面板的材质、配色和背景。
- 通知面板可分别控制快速设置、媒体、弹窗和日历的美化范围。
- 底色不透明度支持 0% 到 100%。0% 去除底色，玻璃材质仍按模糊设置渲染。100% 使用纯色。云母使用同色底色。Windows 关闭透明效果时使用纯色。

「字体颜色」可分别选择自动调整、跟随 Windows 的系统配色、自定义白色和自定义黑色。自动调整会在可读取半透明面板背景时选择黑字或白字。快捷设置的未开启按钮使用淡色玻璃底，已开启按钮使用 Windows 强调色。

Dock 快捷设置的「开始菜单」依次循环跟随本应用、自定义、系统默认。前两档使用 Windows 11 玻璃网格，系统默认档恢复 Windows 菜单。

总设置 → **任务栏 → 效果与文字** 的“文字随壁纸自动切换黑白色”默认关闭，也可在快捷设置的“任务栏文字”中选“随壁纸自动配色”。开启后，从任务栏所在屏幕的壁纸边缘取色，亮壁纸用黑字，暗壁纸用白字。切换前台窗口时字色保持稳定。Windows 各屏任务栏共用一种字色，优先采用 Dock 所在屏幕的任务栏，该屏没有任务栏时采用主任务栏。系统默认任务栏跟随 Windows，退出 Dock 恢复原设置。

桌面收纳卡片与资源胶囊共用 110×20 逻辑像素的切页控件。鼠标移到底部中央时透明浮出，移走收起。点击箭头或在页名上滚动可切页。备注和拖入提示显示在各自卡片内。

设置窗口的小、中档空间扩大 20%，文字和控件密度保持原值；每次打开默认中档。小屏幕仍限制在工作区以内。

## 状态与还原

状态显示「等待系统面板打开」「已应用」或具体失败信息。点击「重试接入」重新连接已保存的配置。「恢复此页默认外观」取消此页开关，保存后还原。正常退出应用和 Windows 注销会停止接入并恢复控件原值；应用异常退出时，原生后端通过主进程句柄检测退出并执行还原。

已保存的美化开关在下次启动时继续使用。系统目录或宿主尚未就绪时按间隔重试；宿主重新启动后自动重新连接。双列布局保留系统控件的父容器、数据绑定和命令关系。

Shell 窗口创建或显示时会立即唤醒接入检查，后台仍每五秒检查一次。通知面板新建界面线程时，从首批控件创建事件开始应用样式。关闭或切换外观时先停止布局和样式监听，再逐个恢复原值；失效控件的还原异常记录到状态，其他控件继续恢复。

更新后，Dock 等待已加载的旧开始菜单组件还原，再启用新版本。状态会分别显示组件切换和等待搜索入口显示。打开玻璃网格后，在底栏设置齿轮的左侧可看到搜索按钮。

快捷设置和通知中心由不同系统进程承载。任一进程尚未接入或失败时，状态会显示“部分已应用”并保留失败原因，不把另一个进程的成功当作全部成功。

后端仅连接同一会话内 Windows 系统目录中的 StartMenuExperienceHost、SearchHost、ShellExperienceHost 和 ShellHost，不修改系统文件，不注册服务，不关闭或重启这些进程。组件先校验 SHA-256，再放入 `%LOCALAPPDATA%\BigFishDock\ShellAppearance\<构建编号>`；设置与状态放在 `%APPDATA%\BigFishDock\shell-appearance`。单文件版不会依赖启动临时目录中的 DLL 长期运行。

受沙箱隔离的通知中心和 Windows 搜索使用各自包的 `%LOCALAPPDATA%\Packages\<包名>\LocalState\BigFishDock\shell-appearance`。当前 Dock 提供等待／查询句柄和该进程专用状态文件的写入句柄，通过包内事件刷新配置。搜索以只读方式取得开始菜单外框的屏幕坐标。

## 兼容与验证边界

适用于 Windows 11 x64。Windows 10 保留系统外观。Windows 更新、企业策略或其他系统美化工具可能影响原生控件匹配或阻止接入；遇到不兼容可关闭此功能，原有 Dock 和桌面组件仍可使用。

验证在隔离 Windows 桌面运行，覆盖带边距的 XAML 宿主、完整应用列与固定图标点击区域、嵌套账户和电源控件、搜索窗口反复重定位、裁切与恢复、没有开始菜单坐标时的搜索位置、原生二级菜单、搜索样式、Qt 设置和主进程生命周期。隔离场景使用原生 XAML 模拟系统层级，实际 Windows 菜单效果另行核对。

双列对齐会处理系统列表与固定网格内部的边距、内容呈现器内边距和居中布局；控件延后加载或再次布局时继续校正，属性已经正确时不重复写入。隔离检查包含系统重新施加内边距以及列表名称变化的场景，保留面板尺寸、四列图标大小和原生点击区域。

开始菜单的列根节点保留系统开关动画使用的 CompositeTransform 类型。RootContent 创建时即登记布局监听，随后加载的列表和内部模板也会进行对齐。通信句柄、进程身份等连接信息变化不重新还原样式；外观配置变化时才更新样式。

开始菜单按 XAML 排版坐标定位。应用列表独占网格中列且两侧是固定空白时，列表可跨过这两列留白。开关动画由系统绘制，长名称和点击区域限制在本列内。若一分钟内有三个开始菜单进程都在接入后十五秒内退出，Dock 暂停本次开始菜单美化。通知与日历继续工作，点击「重试接入」可重新启用已保存的开始菜单样式。

Dock 优先连接任务栏日期所在的宿主。日历取得名称并首次获得可见尺寸时应用样式。Windows 挂起面板期间，Dock 保留待完成的版本交接，首次展开时立即继续。状态文件的 `calendar_matched` 记录日历匹配结果，`search_input_px` 记录搜索框的屏幕位置。Win+S 展开动画结束时会自动刷新搜索内容。
