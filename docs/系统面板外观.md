# 系统面板外观

入口：总设置 → 外观与系统 → **开始菜单 / 通知面板**。保存后应用，默认关闭。无需安装 Windhawk，也无需向其他软件导入配置。

右键 Dock 或主托盘图标，可切换开始菜单样式、外观来源和通知美化范围。右键菜单和 Dock 快捷设置即时保存并同步设置页。任务栏子菜单提供自动文字配色、手动黑白字和外观设置入口。

## 布局与位置

| 系统区域 | 外观与操作 |
| --- | --- |
| 开始菜单 · 系统默认 | 由 Windows 提供布局与外观。 |
| 开始菜单 · Windows 11 玻璃网格 | 左侧原生应用列表，右侧固定应用网格。 |
| 快速设置 | 玻璃面板与圆角按钮，仍使用系统网络、蓝牙、音量等控件。 |
| 媒体控制 | 统一背景、圆角和封面边角，继续控制系统当前媒体会话。 |
| 通知与日历 | 统一通知列表、日历和通知弹窗外观，保留 Windows 通知内容与操作。 |

点击系统开始按钮或按 Win 键仍在系统开始菜单位置弹出；Win+A、Win+N 和系统通知保留原来的右侧位置。程序不创建一个屏幕中央的替代面板，也不重设任务栏对齐方式。

## 外观设置

- **跟随本应用**读取「Dock 外观」中的材质、明暗、背景色、不透明度、模糊开关、模糊强度和高光。开始菜单与通知面板共用这些参数和面板渲染规则。
- **跟随系统**：跟随 Windows 明暗与透明效果。
- **自定义**：分别设置开始菜单与通知面板的材质、配色和背景。
- 通知面板可分别控制快速设置、媒体、弹窗和日历的美化范围。
- 底色不透明度支持 0% 到 100%。0% 去除底色，玻璃材质仍按模糊设置渲染。100% 使用纯色。云母使用同色底色。Windows 关闭透明效果时使用纯色。

「字体颜色」可分别选择自动调整、跟随 Windows 的系统配色、自定义白色和自定义黑色。自动调整会在可读取半透明面板背景时选择黑字或白字。快捷设置的未开启按钮使用淡色玻璃底，已开启按钮使用 Windows 强调色。

Dock 快捷设置的「开始菜单」依次循环跟随本应用、自定义、系统默认。前两档使用 Windows 11 玻璃网格，系统默认档恢复 Windows 菜单。

总设置 → **任务栏 → 效果与文字** 的“文字随背景自动切换黑白色”默认关闭。开启后读取 Dock 所在屏幕的实际任务栏底色，背后窗口变化时更新文字与系统图标。读取不到时采用材质和壁纸估算。系统默认任务栏继续跟随 Windows。也可点击快捷设置的“任务栏文字”循环到“随背景自动配色”。多屏共用 Windows 的文字配色，退出 Dock 恢复原设置。

桌面收纳卡片与资源胶囊共用 110×20 逻辑像素的切页控件。鼠标移到底部中央时透明浮出，移走收起。点击箭头或在页名上滚动可切页。备注和拖入提示显示在各自卡片内。

设置窗口的小、中档空间扩大 20%，文字和控件密度保持原值；每次打开默认中档。小屏幕仍限制在工作区以内。

## 状态与还原

状态显示「等待系统面板打开」「已应用」或具体失败信息。点击「重试接入」重新连接已保存的配置。「恢复此页默认外观」取消此页开关，保存后还原。正常退出应用和 Windows 注销会停止接入并恢复控件原值；应用异常退出时，原生后端通过主进程句柄检测退出并执行还原。

快捷设置和通知中心由不同系统进程承载。任一进程尚未接入或失败时，状态会显示“部分已应用”并保留失败原因，不把另一个进程的成功当作全部成功。

后端仅连接同一会话内 Windows 系统目录中的 StartMenuExperienceHost、ShellExperienceHost 和 ShellHost，不修改系统文件，不注册服务，不关闭或重启这些进程。组件先校验 SHA-256，再放入 `%LOCALAPPDATA%\BigFishDock\ShellAppearance\<构建编号>`；设置与状态放在 `%APPDATA%\BigFishDock\shell-appearance`。单文件版不会依赖启动临时目录中的 DLL 长期运行。

受沙箱隔离的通知中心改用它自己包的 `%LOCALAPPDATA%\Packages\<包名>\LocalState\BigFishDock\shell-appearance`。仅共享当前 Dock 的等待／查询句柄和该进程专用状态文件的写入句柄，并通过包内事件刷新配置；不放宽应用目录或系统目录 ACL。

## 兼容与验证边界

适用于 Windows 11 x64。Windows 10 保留系统外观。Windows 更新、企业策略或其他系统美化工具可能影响原生控件匹配或阻止接入；遇到不兼容可关闭此功能，原有 Dock 和桌面组件仍可使用。

验证在隔离 Windows 桌面运行，覆盖原生 XAML 材质、玻璃网格两列布局、属性还原、Qt 设置和主进程生命周期。

开发后端及来源见 [ShellAppearance 构建说明](../tools/ShellAppearance/README.md)。
