## 不应混作软件内置能力的内容

- 视频中的动态壁纸与 Wallpaper Engine：早期视频最后打开了 Wallpaper Engine，并演示 Windows 任务栏自动隐藏设置。这不能证明 GlassBoard 自带壁纸引擎，或由软件直接控制任务栏隐藏。
- 视频右上角 FPS、GPU、CPU、延迟等叠加信息：没有足够画面确认归属于 GlassBoard，暂不列为其内置系统监控组件。
- 老视频简介写明仅测试过 Windows 11，不能据此承诺 Windows 10 或其他系统兼容。
- 付费、许可证、源码开放、第三方账户权限、真实资源占用和长期稳定性：两个视频不足以确认。

## 与 BigFishDockpro 的边界

清单是视频参考，不能据此推定所有功能已进入 BigFishDockpro。后续经用户授权，BigFishDockpro 已实现独立的多个桌面玻璃收纳面板、文件自动分类/搜索与 Dock 分页、自启动/延迟/优先级、游戏/全屏检测及更新检查设置；屏幕圆角与精简模式为本项目新增。天气、音乐、时钟组件、备忘录和悬浮控制球仍未加入。线上更新源尚待配置，特定游戏和多显示器仍待真实环境验证。
