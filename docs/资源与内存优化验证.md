## 1.2.0 复测

Bridge 使用 Windows 强制的 47 MiB 总工作集上限，托管堆预算为 16 MiB。实际音频回环输出 20 个频段。总工作集峰值为 47.00 MiB，私有工作集峰值为 8.29 MiB，私有提交峰值为 11.62 MiB。该轮仅开启桌面频谱，未执行 AI 账号读取。

在同一个隔离源码进程里，空载、显示一张自定义卡片、打开原生编辑器的私有工作集中位数分别为 27.20、28.28、35.13 MiB。样本使用注入读数。原生编辑器与卡片渲染的三个压缩代码模块合计 19,989 字节，其他界面和采样接入代码另计。

本轮保留 Python/PyQt 主程序，将 AI/音乐辅助程序改为调用共享 .NET 10 桌面运行库，并优化实际保留的缓存和页面对象。没有采用定时清空工作集、`EmptyWorkingSet` 或强制回收来制造较低的任务管理器读数。

## 1.1.6：表情一致性与主进程继续减量

资源胶囊与桌面收纳卡片共用 `widget_face.py`：250 ms 接近检测、交互时 33 ms 短动画，精简模式仍跟随鼠标；每帧只请求重绘表情区域，隐藏或关闭互动后停止计时。桌面卡片默认不开启表情，不增加新的进程或 UI 运行库。

- 共享壁纸解码上限降为约 1 MiB；大尺寸模糊结果保持半尺寸像素并设置对应 DPR，逻辑覆盖范围不变。文字、图标和边框仍原生绘制。
- Qt 图片缓存限制 1.5 MiB。原生 GPU/核心数组按 16 KiB 分档复用，单缓冲最多 16 MiB，关闭查询时释放。
- 资源设置仅在首次进入栏目时创建控件及滚动区，保存不覆盖未访问栏目；已关闭的主设置、隐藏应用列表、发现结果及可重建图片缓存在空闲时释放。
- 主程序清单启用 Windows Segment Heap（受支持系统）；内存维护仅在空闲且私有工作集达到 44 MiB 时触发，常规巡检至少间隔一分钟。归还未使用的堆块，不清空工作集，不强制 GC，不对主程序设会导致分配失败的硬上限。

机制依据：[微软应用清单 heapType 文档](https://learn.microsoft.com/en-us/windows/win32/sbscs/application-manifests)、[HeapSetInformation](https://learn.microsoft.com/en-us/windows/win32/api/heapapi/nf-heapapi-heapsetinformation)。Segment Heap 的内存和响应表现需结合应用实测，不能仅凭清单配置判定改善。

| --- | ---: | ---: |
| 原配置及壁纸材质 | 42.52 MiB | 47.82 MiB |
| 加入真实原生计数器 | 43.98 MiB | 48.72 MiB |
| 六页反复切换后 | 47.01 MiB | 51.64 MiB |
| 打开资源设置 | 53.93 MiB | 60.35 MiB |

这是私有工作集样本，不是整个进程组或含共享 DLL 页的总工作集，也不是长期峰值保证。**常驻样本已低于 50 MiB，打开设置仍超过，全部功能始终低于 50 MiB 的目标尚未达到。** 测试没有账号查询、网络天气、真实通知或实际播放，不能冒充这些组合的测量；用户正在运行的程序未被替换或重启。

## 已完成的调整

- 玻璃共享壁纸缓存现最多约 1 MiB，保持逻辑坐标；大尺寸背景纹理半尺寸，文字和边框原生输出。
- 合并的 AI 页面和音乐页面首次打开时才创建；统计汇总只在数据、日期或筛选变化时重算。
- 音乐组件仅在频谱实际可见时采样声音；任务栏组件关闭后让出空间。不需要歌词的任务栏音乐不启动歌词匹配。
- 关闭 AI 后释放用量读取器、历史和价格缓存；没有任何 AI/音乐需求时退出辅助进程。
- 辅助程序使用无窗口 Dispatcher，不创建 WPF Application；传给 Qt 的封面最长边限制为 256 像素。
- 界面切换不重复触发全部历史读取，减少不必要的账号刷新。

## Wisland 交互与可选信息组件
