# 便签卡片

入口为 Dock 右键或托盘“更多工具 → 便签卡片”，也可在设置的“桌面收纳”页新建、管理便签。便签与文件收纳相互独立，首次运行不自动创建。

## 可选样式

| 样式 | 特点 |
| --- | --- |
| 液态玻璃 | 复用 Dock 玻璃渲染，半透明高光，背景抓取不支持时保留静态半透明效果 |
| 经典纸张 | 暖色纸面、柔和渐变和标题分隔线 |
| 极简纯色 | 平整底色与细边框 |

新建便签默认样式在设置中选择并保存；已有便签通过各自的“⋯ → 外观样式”切换，内容保持不变。每种样式都可选择七种配色。标题左侧拖动手柄移动，右下角调整大小；“−”收起为标题条，再次点击展开。菜单可置顶、锁定位置、隐藏或删除。

## 编辑与保存

- 支持加粗、斜体、下划线、删除线和项目符号；Ctrl+B / I / U 设置格式，Ctrl+Shift+L 切换项目符号。
- 待办按钮在当前行加入方框，点击方框或再次使用按钮切换完成状态，保留原文字格式。
- 编辑后 600 ms 自动保存到本机，Ctrl+S 或“↻”立即保存；失败时保留窗口内容并显示重试提示。
- 便签管理支持标题与正文搜索、隐藏便签重新打开、最近删除恢复。删除保留最近 32 张，活动便签最多 64 张；单张正文最多 32000 字符，便签与最近删除总数据最多 4 MiB。
- 普通粘贴使用纯文字；便签文档不读取外部图片或本地资源。没有账号登录或云同步。

常规退出先保存，主配置写入失败时尽力写入数据目录 `notes-recovery.json`，下次启动恢复；无法保存也无法备份时，通过 Dock / 托盘“退出”会保留程序并提示先复制内容或修复目录。系统强制终止或磁盘完全不可写仍可能丢失尚未保存的内容，不将恢复机制称为绝不丢失。

## 运行模式与迁移

游戏及前台全屏隐藏规则沿用当前运行模式；精简时保留编辑和自动保存，停止便签背景抓取。位置与尺寸保留参考屏幕工作区，按屏幕比例调整内部字号，手动移动后保存当前比例，避免累计放大。

配置导入导出包含便签正文、样式、最近删除和位置，不再只有应用/文件的路径引用。导入先显示便签数量，保存后应用；导入前备份也包含现有便签。便签有未保存内容且保存失败时，设置提交会停下，避免直接覆盖。

### 便签标题与正文字号（1.0.4）

- 标题默认作为文字显示，双击后编辑；Enter保存、Esc取消，点击其他位置也会结束编辑。标题区域随文字长度收紧，长标题限制宽度并可悬停查看，不占满整行。
- 标题栏的滑杆图标直接打开“便签设置”，无需先进入右键菜单。可修改样式、颜色、正文大小、自动收起、置顶与锁定；保存后窗口保持打开。
- 每张便签的正文字号可单独设置8–72像素。标题和按钮仍使用卡片字号；调整全局卡片字号不会覆盖已单独设置的正文。点击“跟随卡片”可恢复默认关系。字号参照随屏幕/整体缩放适配，独立宽高不受影响。
- 正文字号包含在本机保存、配置导入导出、最近删除恢复和异常退出备份中。取消或保存失败保留原设置，编辑标题时正文自动保存不会写入未确认的标题。

以上补充覆盖前面“所有便签正文必须跟随卡片字号”的旧说明。本轮进行隔离桌面运行检查及成品启动/退出验证，实际结果见验收记录。
