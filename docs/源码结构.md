# 源码结构与入口

- `app/`：Dock、卡片、便签、时钟、设置、原生文件操作及运行服务。
- `tests/`：隔离运行检查；`fixtures/` 只保存测试程序源码。
- `tools/`：构建、打包定义、安装器定义、依赖清单、隔离桌面运行器、版本和源码导出工具。
- `assets/`：应用 ICO 与 Windows 清单；源码与打包后的资源使用相同逻辑位置。
- `docs/` 与 `licenses/`：文档、截图和第三方许可。

根目录 `dock.py` 将源码模块目录加入搜索路径，再进入 `app/dock.py`；实际程序源码仅保留在 `app/` 中。根目录 `build.ps1`、`bootstrap.ps1` 转发到 `tools/`，保留现有一键命令。

从项目根目录执行：

```powershell
.\.venv\Scripts\python.exe dock.py
.\build.ps1
.\.venv\Scripts\python.exe tools\run_isolated_test.py --target dock.py --python .venv\Scripts\python.exe --output artifacts\source-check --runtime-check
.\.venv\Scripts\python.exe tools\release_tools.py deliver
```

精简源码导出按文件夹保留结构，排除字节码缓存；旧版根目录中的已知模块按迁移清单清理，保留 `.git` 和用户添加的未知文件。应用配置仍由应用数据目录管理，源码迁移不修改运行配置。
