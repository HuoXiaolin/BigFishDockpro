# 轻透分组设置

设置窗口采用浅蓝框架、白色内容区与左侧分类；相关选项按材质与颜色、质感与尺寸、停靠与交互等分组。

![主设置](screenshots/settings-light-groups.png)

- 材质和颜色模式并排，主题色保留自定义输入、选色和七种色块。
- 常用外观参数支持滑块和数值输入双向同步；数值范围与原设置一致。
- 窄窗口自动改为单列，内容在设置区域滚动，底部操作栏保留。
- 应用管理、卡片外观、便签、时钟、日历、图标编辑、分组、新建面板及收起设置共用字体、间距、按钮与明暗配色。
- 弹窗继承已保存的界面尺寸，主窗口标题区右侧可选择自动、小、中、大或手动调整。
- 主设置和原有可连续编辑的窗口保存后保持打开；新建面板等确认型窗口仍按原流程返回结果。
- 九宫格快捷设置保留滚轮翻页、排序与现有功能，改用清晰的实色底和状态反馈。

Dock 配色示意按需绘制，不启用定时刷新或前台取样；时钟与日历仍使用现有实际预览。

本次验证采用独立 Windows 桌面上的原生 Qt 控件渲染和本机临时配置。物理显示器切换、真实跨屏 DPI 和安装器安装仍需实际使用环境复核。
