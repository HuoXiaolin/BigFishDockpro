# 版本迭代清单

## 2026-10-23 · 1.0.1

基线为 1.0.0，项目和文件名继续使用 BigFishDockpro，中文名大肥鱼Dock。按既有北京时间自然日版本规则递增，Windows 数字版本为 1.0.1.0。

| 项目 | 实现与验收要点 |
| --- | --- |
| 首次运行 | 无配置时显示 Dock、桌面卡片关闭；空列表引导拖入及 Dock 右键管理 |
| 设置结构 | 六个标准分组，应用排序与运行标记归入应用管理 |
| 卸载入口 | 扫描过滤卸载名称、目标与参数，保留原文件和固定记录 |
| 菜单 | 托盘/Dock/卡片统一文字列、勾选和子菜单箭头；卡片菜单关闭后释放，删除后不访问已移除配置 |
| 下拉框 | 统一 Qt 列表弹窗，全部设置下拉在浅/深主题打开；Enter 提交、Esc 取消，窗口边缘定位与高 DPI 检查 |
| 启动恢复 | 保存 Dock、面板显隐、托盘、完整/精简模式、页码、卡片收起、合并当前页与尺寸；普通与 --autostart 真入口验证 |
| 分组 | 默认七类可关闭再开启；扫描不重新打开已关闭组；保留收纳数据与独立外观 |
| 合并分页 | 单一卡片显示，顶部栏目切换，保存活动页面与共享尺寸；取消合并保留独立布局 |
| Dock 右键 | 设置、应用批量管理快捷入口；保留图标设置与移除 |
| 自动精简 | 设置关闭后 60000 ms；保存不关闭不计时；打开设置停止并恢复，其他编辑窗口/菜单在用时延后；原卡片展开状态恢复 |
| 格式规则 | 新建/编辑面板设置扩展名，快捷方式目标格式匹配；同文件多处引用、单面板排除与置顶独立，删除不影响其他引用 |
| 托盘隐藏 | 设置中控制显隐；Dock 右键或再次运行已有实例可进入设置 |
| 卡片视图 | 小图标、大图标、列表独立保存，切换不改收纳、排序与置顶 |
| 材质 | 同色同背景六种绘制比较；不同模糊/底色/高光/细粒度，云母是软件模拟；全透明切换恢复基础可见参数 |
| 配置与交付 | 保留旧数据兼容目录，旧配置归一化；保存失败不提交；源码和两种成品隔离回归、逐文件哈希与最终版本核对 |

默认首次运行显示 Dock、桌面收纳关闭；已有配置保留。设置栏目统一为外观设置、桌面收纳、应用管理、启动与运行、更新设置、关于与数据。

过程和限制见[本地验收记录](验收记录.md)。1.0.0 的历史更新和测试结果保留，不改写为本轮结果。未执行远端推送、真实系统重启/登录和长时间实际桌面运行验证。


## 2026-10-23 · 1.0.1 · 第 16–19 项

- 列表显示：11 个文件逐行排列、滚动到末项，重复切换三种视图，搜索与选中项保持。
- 选择性合并：卡片右键直接加入/独立；分组管理逐组选择；独立卡片与合并卡片同时显示，各自几何和状态保存。
- 设置按钮：移除鼠标焦点内圈，保留键盘导航；删除重复的“显示桌面面板”入口。
- 沿用同日版本规则；完整构建、交付核对与实际限制见验收记录。


## 2026-10-23 · 1.0.1 · 分组栏目排序

新增顶部栏目拖动排序并自动保存，管理页上移/下移后保存；保留分组身份、独立/关闭分组位置和文件引用。覆盖拖动未选中分组的释放时机、保存失败回退、管理页取消与重新载入；不与卡片内文件排序混用。


## 2026-10-23 · 1.0.1 · 屏幕布局比例保持

新增持久屏幕基准、工作区相对位置与等比尺寸映射；Dock 同步图标及偏移。临时缩屏/拔屏不覆盖原布局，手动卡片位置尺寸建立新基准。覆盖负坐标副屏、换屏回连、重启、合并/独立/锁定/收起、重复映射和保存失败；旧配置建立当前基准，物理多屏实测与隔离模拟区分记录。


## 2026-10-24 · 1.0.2 · 外接屏与笔记本混合 DPI

修复外框与内部指标不同步，移除系统 DPI 二次补偿；设置每屏 DPI 感知和分数缩放策略。覆盖同 2K 的 100%→150% 模拟、原生窗口感知、字体/图标/网格/行距一致、重复通知及手动移动后视觉比例持久化。普通设置与外观弹窗字体保持独立；真实两屏插拔另行确认。


同批补充：应用批量管理第四栏“正在运行”，按需后台读取当前桌面有窗口的软件，含最小化窗口；刷新/搜索/多选/已固定过滤/图标/暂存保存与取消。原生后台线程也验证隔离桌面，关闭取消读取并释放数据，不启动其他应用、不改正在运行的进程。


同批补充配置迁移：关于与数据中的 JSON 导入/导出、只导出已保存配置、兼容原始 config.json、预览后保存及取消、原配置备份、无效类型与跨项目文件拒绝、同 id 卡片位置覆盖、保存和应用失败回滚、批量管理未保存改动冲突检查。


同批补充紧凑界面：设置默认 560×448、应用管理默认 518×406（逻辑像素），宽高为旧版 70%，占屏面积约减半；图标设置、面板外观、新建面板、分组管理、下拉列表和右键菜单同步压缩。保留可读文字、键盘焦点及手动缩放；重复打开或切换主题不累计压缩，不更改 Dock/卡片保存大小。


同日继续 1.0.2：修复外部程序继承单文件运行库路径造成的退出清理失败；桌面图标提供并存、仅隐藏已收纳项目、全部隐藏三种模式，按项隐藏含恢复记录及扫描兼容。按用户确认新增三种可选便签样式、基础编辑、可点击待办、本机自动保存、搜索、删除恢复、运行模式和比例布局、配置迁移及失败备份。没有另加账号、云同步或提醒服务。


## 2026-10-25 · 1.0.3 · 卡片字号尺寸与设置自动适配

补齐卡片70%紧凑比例与高分辨率初始尺寸适配，逐卡片宽高/文字设置，合并页共用尺寸但文字独立，修复便签延迟几何保存重建参照。设置窗口自动、小中大三档及手动尺寸记忆同步缩放控件/字号；写入失败不应用，源代码专项与成品全量/启动验证分开记录。
