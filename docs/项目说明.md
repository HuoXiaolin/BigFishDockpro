## 命令

```powershell
./bootstrap.ps1
.\.venv\Scripts\python.exe tools/run_isolated_test.py --target dock.py --output artifacts/source-test
./build.ps1                       # 构建和隔离验证，不同步共享交付目录
./build.ps1 -Deliver              # 构建通过后同步本项目精简源码及安装包
.\.venv\Scripts\python.exe tools/release_tools.py deliver   # 导出本次已验证产物
```

`tools/run_isolated_test.py` 是唯一 GUI 自检入口；直接执行 `--self-test` 缺少隔离上下文会失败，禁止回退当前桌面。截图和测试 JSON 位于指定输出目录。工具不切换用户输入桌面。

## 版本和导出

按北京时间自然日，当天首个成功交付递增一次第三段，满 9 向第二段进位；同日重试沿用同号。失败不记录成功日期；只有安装包生成、打包成品自检通过、交付文件哈希核对完成，才提交成功日期。构建锁防止并发重复递增。本轮按用户明确要求把项目改名为 BigFishDockpro，并将版本重设为 1.0.0；后续仍按北京时间自然日规则递增。旧版本历史保留。

生成的 Windows 资源和打包版本文件只放 `artifacts/generated`，应用、关于页、安装器及数字文件属性均从这次版本生成。发行提供安装包、用户要求的免安装单文件 EXE 和校验清单。源码按明确清单导出，保留模块、构建脚本、许可、最新与历史日志以及演示截图，不携带 SDK、日志、真实配置、视频、研究工具或测试缓存。现有 `.git` 和未知文件不覆盖。

## 数据与边界

运行数据保留在 `%APPDATA%\BigFishDock`；应用不使用账号数据或下载目录。清理只针对本项目已确认可重建过程文件，不包含用户配置、共享工具链或其他项目目录。公共开发习惯文档只读取，不由本项目维护。

本地编译、隔离测试、安装包生成和本地交付与 GitHub 发布分别记录。本项目没有执行源码提交、推送或 GitHub Release 发布。事件层面的拖放测试不代替真人桌面手势、多显示器、高 DPI 或干净 Windows 机器验收。

本轮开发目录、精简源码目录和正式发行目录同步改名为 BigFishDockpro。产品显示名称为“大肥鱼Dock”；%APPDATA%\BigFishDock、同名自启动注册表值和互斥键为保留的兼容标识。
