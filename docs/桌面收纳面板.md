# 桌面玻璃收纳面板

启用“设置 → 桌面收纳 → 启用桌面悬浮收纳面板”后，面板固定显示在桌面上，独立于 Dock 的应用列表。标题处拖动、右下角缩放，位置与展开尺寸会保存；每个面板可单独锁定。面板不使用常驻置顶标志，挂在桌面窗口所属层级，不作为任务栏应用按钮。

## 自动与手动收纳

- 自动读取个人桌面（包括系统重定向的 OneDrive 桌面）和公共桌面的第一层内容，不递归展开文件夹、不扫描开始菜单。
- 按应用快捷方式/程序、文件夹、文档、图片、影音、压缩包、其他内容建立面板。扩展名规则在 `desktop_catalog.py`；系统隐藏文件和 desktop.ini 不纳入。
- 文件增删触发目录通知后更新，空闲时不进行周期扫描。关闭自动分类后保留现有收纳记录，仍可手动拖入。
- 任意本地文件、文件夹或快捷方式均可从资源管理器拖入指定面板。已收纳的同一路径会调整到该面板，后续自动扫描保留手动归属。
- 面板内可搜索、多选；右键把所选内容收纳到其他面板，或移除引用。移除的路径不会立即被自动扫描加回来，重新拖入可恢复。
- 新建与重命名在面板“⋯”菜单。移除面板需确认，只解除收纳引用，文件本身仍在原位。

文件不复制、不搬迁、不删除，面板保存的是路径引用。此电脑、回收站等系统虚拟图标不属于磁盘文件，本版不生成这些虚拟入口。

## 液态玻璃与布局

面板与 Dock 调用同一份 `liquid_glass.py` 绘制：底色、渐变、高光、柔光与描边沿用 Dock 的主题。设置页提供默认透明度、模糊、高光、材质、锁定与收起形状；各面板“⋯ → 外观与收起”可独立覆盖默认值。

标题拖动、右下角大小手柄调整尺寸；锁定同时限制拖动和尺寸变化。拖动收起条会改变位置，保留原展开尺寸。屏幕移除或分辨率变化后，把面板调整回可见区域。布局保存在 config.json，不与 Dock 固定入口混用。

鼠标离开后自动收起为方条或胶囊，始终保留类别名称、数量和展开入口。点击或悬停展开，拖入内容时也会展开。关闭按钮收起面板；托盘“显示/隐藏桌面面板”可整体显示或隐藏。

精简模式保留收起条与文件目录通知，释放背景图片缓存，停止背景捕获；展开面板会恢复完整模式并重新启动精简倒计时。游戏模式临时隐藏面板，不改变收纳记录或布局。

模糊使用 Windows 允许的背景捕获，在显示、移动/缩放后或手动刷新时更新，不连续抓屏。捕获前排除本软件的 Dock 和所有面板，避免互相拍入；系统不支持捕获排除或面板横跨屏幕时，保留同款半透明玻璃绘制。

## 隐藏与恢复系统桌面图标

面板显示后临时隐藏 Explorer 的桌面图标视图，原文件和系统“显示桌面图标”的注册表选项不修改。关闭面板功能、从托盘整体隐藏面板或正常退出软件时恢复初始可见状态；原本就隐藏的图标保持隐藏。

隐藏前把恢复信息写入应用数据目录的 desktop_visibility.json，写入失败则不隐藏。正常恢复后删除这份临时记录；异常终止时，下一次启动先按记录恢复旧视图，再执行本次面板设置。Explorer 重建图标视图时通过窗口事件重新处理，无空闲轮询。强制终止到下次启动之间可通过 Windows 桌面右键“查看 → 显示桌面图标”手动恢复。

## 验证边界

隔离桌面以模拟文件和测试拥有的原生 SysListView32 验证分类、目录通知、拖放事件、布局、锁定、收起计时、图标隐藏/恢复和恢复记录；不会操作使用者当前桌面。实际 Explorer、Win+D、跨屏 DPI、完整 OLE 拖放手势与玻璃背景显卡兼容性仍需真实环境验证。

## 配套外观预设和主题色

| 面板方案 | 不透明度 | 模糊 | 高光 | 材质 / 明暗 |
| --- | --- | --- | --- | --- |
| 轻透液态 | 38% | 6 | 45% | 液态玻璃 / 浅色 |
| 柔雾玻璃 | 64% | 16 | 35% | 亚克力 / 浅色 |
| 高光玻璃 | 45% | 8 | 75% | 高光玻璃 / 浅色 |
| 沉静云母 | 86% | 12 | 25% | 云母质感 / 深色 |
| 全透明 | 0% | 不抓取 | 0% | 无底色、无边框 / 跟随系统 |

每个面板“⋯ → 外观与收起”单独选方案、明暗和主题色，可选择颜色或填 #RRGGBB。先暂存到弹窗，保存才应用，取消不改设置。主题色为空时使用默认色；“跟随系统”只跟随系统明暗。Dock 与面板主题色分别设置，互不覆盖。修改预设后的任意参数即成为自定义设置，重开弹窗会识别仍完全匹配的方案。

Dock 在“设置 → Dock 与圆角”选轻透液态、柔雾玻璃、高光玻璃、沉静深色或全透明方案，单独调整主题色、高光、通透度和模糊。预设不移动 Dock，不改尺寸、图标、排序、启动项或各面板的独立设置。主题色影响玻璃底色与描边，不染色文件图标和文字。主题色留空可恢复原项目配色。

全透明会真正跳过背景绘制，不是仅把原通透度调到 100。保留文字、图标、搜索和操作入口，交互时仍可显示必要的悬停/选择提示。Dock 的“背景全透明”可单独关闭；面板全透明对应不透明度 0、通透材质、高光 0。

胶囊宽度可在“设置 → 玻璃面板”设默认比例，也可在各面板“⋯ → 外观与收起”分别设置：范围为展开宽度的 30%–100%，默认 70%，最窄 180 像素且不超过当前屏幕可用宽度。方条仍使用展开宽度，调整胶囊比例不改变已保存的展开尺寸。保存外观后弹窗保留，可连续微调；关闭或取消只放弃未保存的改动。

## 排序与置顶

面板菜单的“排序方式”提供文件名升序/降序和修改时间最新/最早优先，分别保存。修改时间采用桌面项目本身的文件修改时间，快捷方式按快捷方式文件时间排序。图标右键“置顶/取消置顶”支持当前选择；置顶项先排，再应用所选排序规则。文件暂时不可读取时按时间 0 处理，保留引用。

快捷方式先读取 Windows 目标路径再分类，不执行或改写快捷方式。文件夹、文档、图片、影音、压缩包按目标类型归入对应面板；网页、失效及无法解析的快捷方式回退应用类。支持本地文件 URL、有限链式解析和循环保护。已有自动记录在扫描时重新分类，手动拖入或跨面板指定后保留手动归属。

颜色模式统一为跟随系统、浅色、深色，旧“光感”配置迁移为浅色加高光玻璃材质；旧“跟随 Dock”迁移为跟随系统。材质使用独立选项，不影响主题色。推荐主题色：冰川蓝 #8FBFE0、薄荷绿 #8FC9B0、青碧 #70B9BC、雾紫 #B3A0D6、樱花粉 #DEA6BB、暖杏 #E5BA8D、石墨灰 #8A95A5。


## 分组、合并与文件格式规则（1.0.1）

设置中的“分组与合并管理”可逐个启停七个默认分组及自定义面板。关闭只隐藏，保留数据和外观；扫描不会自行打开已关闭分组。可选择部分分组合并，在顶部栏目切换，栏目较多时横向滚动；其余卡片独立显示。卡片右键可直接“加入合并卡片”或“独立显示此卡片”，退出合并恢复该卡片的独立位置和大小。

新建面板或面板菜单“自动归入格式”可填写 `.pdf .png .docx` 等扩展名。规则独立匹配桌面扫描内容，快捷方式按目标文件格式匹配；多个面板可重复引用同一文件。单个面板的排除与置顶独立保存，删除自定义面板不影响其他引用或原文件。自动分类关闭后，格式规则暂停刷新，手动引用继续保留。

卡片内右键“显示方式”提供小图标、大图标和列表，独立于排序、置顶和其他分组；关闭、重开和登录恢复后仍保留所选视图。


列表视图逐行显示全部文件，内容超出卡片高度时滚动浏览。设置中的面板启用开关保存后生效；临时显示或隐藏使用 Dock / 托盘菜单，不再保留重复的“显示桌面面板”按钮。


分组栏目支持拖动排序，调整后自动保存；也可在“分组与合并管理”选中一行，点击“上移 / 下移”，最后保存分组。关闭管理页会放弃未保存的排序。栏目顺序不改变文件分类，卡片内文件仍可在右键“排序方式”中按文件名或修改时间排列。


分辨率变化或更换显示器时，Dock 和卡片按屏幕可用区域保持相对位置；卡片宽高按同一比例调整，Dock 图标与边距同步调整。布局以原始屏幕为参照，临时缩屏或断开显示器不会覆盖原参照；原屏恢复后可恢复布局。手动移动、调整卡片大小会建立新的参照。合并卡片与独立卡片分别记录，收起形状和分组顺序继续保留。不同长宽比和极小工作区会限制到可见区域，并保留最小可操作尺寸；自动紧凑卡片仍按内容决定高度。系统 DPI 由 Qt 处理，不重复缩放。旧配置首次升级时以当前屏幕建立参照，无法推算升级前未记录的显示器信息。
