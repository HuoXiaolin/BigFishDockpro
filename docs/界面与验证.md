# 界面与验证

采用 Taste Skill 仓库内 `skills/taste-skill/SKILL.md` 及完整 `references/app-screens.md` 的应用屏规范，保留原生 PyQt5 技术栈。来源：https://github.com/Leonxlnx/taste-skill 。本次为既有弹窗与设置组件调整，沿用组件流程，不随机更换品牌、配色或设计方向，不安装全局技能。

管理页的问题是“哪些入口要添加或移除，哪些改动尚未保存”；主体为可多选列表。设置页按 Dock 与圆角、玻璃面板、应用整理、运行方式、软件更新、数据与关于分组，承载本次已授权功能。统一 Microsoft YaHei UI 字体、中性亮暗主题、6/8 像素圆角、设置页 18 像素水平边距、主次按钮及危险操作颜色。

批量列表保持已选状态，但只操作当前筛选中可见的已选项；筛选外数量明确显示。选择、暂存和保存三个状态分开。取消选择只清除勾选；取消和窗口关闭放弃尚未保存的添加/移除；保存失败保留暂存改动供重试。移除不会删除原文件或卸载应用。

GUI 测试通过 `run_isolated_test.py` 创建独立 Windows 桌面，子进程在 QApplication 创建窗口前绑定该桌面，核对窗口线程桌面名，并通过 Windows UOI_IO 直接证明测试桌面不接收用户输入（也兼容无法打开受保护输入桌面的情况），无法建立或核实时立即失败，禁止回退当前桌面。未调用 SwitchDesktop，也不修改显示或任务栏。测试只使用临时配置和虚构应用数据；截图中的用户路径为 Demo。

本项目不是网页，因此未运行基于 DOM 的 Taste 浏览器检查器；以真实 Qt 控件在隔离桌面渲染和截图检查替代。测试覆盖添加/移除/取消、隐藏选择范围、保存失败重试、去重、配置重载、亮暗主题、全部设置分组及最小窗口。原生拖放事件回归不等于真人桌面拖放、多显示器或干净系统验收。

桌面收纳面板替代此前的共享启动面板，使用紧凑标题、搜索与图标网格。液态玻璃、渐变高光和方条/胶囊是用户明确指定的外观，优先于 Taste 通用应用屏的禁玻璃规则；直接复用原 Dock 绘制，未引入网页框架。按真实控件在亮/暗、100%/150% 下检查展开与两种收起状态。测试绑定独立桌面，仅创建模拟文件与测试图标视图，禁止扫描真实桌面或隐藏用户图标。

设置页本轮统一为中性侧栏导航，导航选中项与内容使用同一索引；字段标签统一 130 像素列宽，窄窗口自动换行。输入框、下拉、数字增减、可换行复选框、按钮和横纵滚动条共用一套字体、约 34 像素设置主控件高度与亮暗色；下拉箭头和数字增减为 QPainter/Qt 按钮实现，未引入图像或额外 UI 运行库。Windows 支持时对原生弹窗标题栏同步明暗及颜色。源自同一全透明方案的背景 Alpha 检查为 0，文字和操作仍可见。

设置页默认为 800×640，最小 640×480；正文 14 像素。标题栏使用细线矢量按钮，提供最小化与关闭，标题区域可拖动，右下角保留缩放柄。保存后保持当前页和滚动位置，显示成功提示；保存不发出关闭信号，也不启动关闭后 60 秒精简倒计时。仅真正关闭设置页才进入该计时流程。

批量管理与 Dock 图标设置沿用相同紧凑样式、细线标题按钮与 14 像素正文。批量管理复用 Dock 图标缓存，添加与已固定列表均显示 28 像素图标；搜索与勾选不反复提取图标。保存成功保持页面打开，暂存计数复位，保存失败保留草稿。图标编辑支持名称、图片/程序图标及目标链接，保留原快捷方式文件，错误链接和并发修改给出提示。

Dock 与面板共用 MATERIALS / COLOR_MODES 常量：六种表面材质和三种明暗模式。高光玻璃作为材质，颜色模式只控制系统/浅/深；主题色为独立七色色块和自定义字段。正文与字段列宽一致，Dock 不透明度界面值与旧 transparency 配置反向映射，旧配置不丢失。窗口统一从打包的 dock.ico 获取应用图标。

收纳面板使用 34 像素图标、78 像素网格，收紧标题、搜索栏及边距；少量内容按实际行数缩短高度，较多内容在高度上限内滚动。长文件名显示省略号，悬停显示完整路径。搜索不改变窗口高度；手动缩放保存自定尺寸，右键“按内容紧凑排列”恢复适配，锁定时保持尺寸。
