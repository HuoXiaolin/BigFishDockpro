# 卡片尺寸与设置窗口适配

## 桌面卡片和便签

- 设置 → 桌面收纳 → 卡片整体缩放：默认70%，范围50%–150%，同时调整桌面卡片、便签的外框和内部布局。原有屏幕参照保留。
- 卡片菜单 / 便签“⋯” → 尺寸与文字；也可在设置页打开统一窗口，选择目标卡片。
- 宽度、高度、文字大小显示当前屏幕的界面像素值，Windows缩放由Qt处理。保存保持设置窗口打开，可继续微调。
- 桌面卡片勾选按内容自动调整高度后，由内容决定高度，取消勾选可手填高度。图标大小仍可从卡片“显示方式”选择小图标、大图标、列表。
- 合并卡片共享宽高，每页文字大小独立；收起状态下编辑的是展开尺寸，保存后保留当前收起和锁定状态。
- 文字放大后列表行高及图标网格同步容纳文字，内容超出时滚动，避免重叠或只显示一项。
- 新建卡片按当前可用工作区获得初始尺寸；高分辨率不会继续使用相同的小像素初值。已有手动尺寸保留，自动换屏投影不覆盖大屏参照。

宽高受当前可用区域和最小可操作尺寸限制。文字设置独立保存当前比例参照，改宽高不会把字号一起任意改变；全局比例或换屏时仍按参照一起适配。写入失败保留原尺寸与字号。

## 设置窗口

右上角“窗口大小”提供：

| 模式 | 行为 |
| --- | --- |
| 自动适配 | 按当前屏幕可用界面区域选择档位；分辨率高时使用更大字号与控件 |
| 小 | 560×448，紧凑布局 |
| 中 | 800×640，标准布局 |
| 大 | 1200×960，更大字号、控件、色块和间距 |
| 手动调整 | 拖动右下角后进入，保存当前宽高和此前字号档位 |

以上宽高为系统缩放后的界面尺寸，屏幕不足时限制在可用区域内。自动档在可用宽至少3000或高至少1700时选择大；至少1550×850选择中；其余选择小。手动尺寸保存后，在小屏重新打开时会限制显示范围，返回可容纳的屏幕再按已存尺寸恢复。

点击“保存设置”记录当前选择；关闭放弃未保存的模式和手动尺寸。切换主题或重复打开不累计放大。卡片尺寸设置弹窗跟随已保存的界面档位，右键菜单继续保持紧凑。

## 验证说明

本批使用私有Windows桌面和演示数据，检查卡片宽高/字号独立保存、失败回退、11行大字列表、合并页和收起状态、三档设置与模拟4K工作区、手动尺寸在小屏的限制与重开恢复。100%、150%、200%属于专项源码界面检查，最终成品另有完整回归与三种缩放的真实启动检查；未改变当前Windows显示设置，不把这些结果称为实体换屏实测。
