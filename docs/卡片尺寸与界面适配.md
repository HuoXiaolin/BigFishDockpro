# 卡片尺寸与设置窗口适配

## 桌面卡片和便签

- 设置 → 桌面收纳 → 统一卡片尺寸与文字；卡片和便签菜单也进入同一个窗口，不再逐张选择。
- 统一宽、高、文字大小，覆盖所有现有、新建、关闭后重开及从最近删除恢复的桌面卡片和便签；合并页同样一致。
- 保存保持窗口打开，位置、内容、颜色、收起与锁定分别保留；宽高指展开尺寸，内容超出时滚动。
- 去掉逐卡片自动高度和独立改大小入口，通过统一窗口主动调整。整体缩放与换屏继续按屏幕参照适配；小屏限制在可用区域内。
- 旧逐卡片宽高/字号字段作为兼容数据保留，实际显示由统一配置控制，配置导入导出携带统一设置。

## 设置窗口

右上角“窗口大小”提供：

| 模式 | 行为 |
| --- | --- |
| 自动适配 | 按当前屏幕可用界面区域选择档位；分辨率高时使用更大字号与控件 |
| 小 | 560×448，紧凑布局 |
| 中 | 800×640，标准布局 |
| 大 | 1200×960，更大字号、控件、色块和间距 |
| 手动调整 | 拖动右下角后进入，保存当前宽高和此前字号档位 |

以上宽高为系统缩放后的界面尺寸，屏幕不足时限制在可用区域内。自动档在可用宽至少3000或高至少1700时选择大；至少1550×850选择中；其余选择小。手动尺寸保存后，在小屏重新打开时会限制显示范围，返回可容纳的屏幕再按已存尺寸恢复。

点击“保存设置”记录当前选择；关闭放弃未保存的模式和手动尺寸。切换主题或重复打开不累计放大。卡片尺寸设置弹窗跟随已保存的界面档位，右键菜单继续保持紧凑。
