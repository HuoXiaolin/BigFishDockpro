# 卡片尺寸与设置窗口适配

## 桌面卡片和便签

- 在「桌面卡片与收纳 → 分组与尺寸」打开「尺寸与文字」，也可从卡片或便签菜单进入。
- 文字大小应用到所有现有、新建和恢复的卡片、便签，手动改变宽高不会另存不同字号。
- 默认宽高只用于新卡片。独立卡片和便签可拖动右下角改变大小，分别记忆；合并页面共用宽高，切换分组不按内容改变高度。
- 保存字号不改变现有宽高。位置、颜色、内容、锁定和收起状态分别保留；缩放和换屏继续使用屏幕参照。
- 设置操作按钮按用途并排，避免单个操作铺满整行；长说明移到关联控件的提示中。

## 设置窗口

总设置默认以中号打开，可在右上角切换「界面尺寸」。

| 模式 | 行为 |
| --- | --- |
| 自动适配 | 当前显示器的可用区域达到 1550 × 850 逻辑像素时使用中号，其余使用小号 |
| 小 | 768 × 560 逻辑像素，适合紧凑工作区 |
| 中 | 960 × 700 逻辑像素，可同时看到更多分类和设置 |
| 手动调整 | 拖动右下角后进入，保存当前宽高和此前字号档位 |

主设置和组件设置按当前显示器的可用空间限制宽高，内容较多时可上下滚动。灵动胶囊设置在中号下默认 832 × 620 逻辑像素，分类和内容并排显示。

拖动总设置右下角后，点「保存设置」记住尺寸。下次可选「手动调整」取回。组件设置采用已保存的界面档位。
