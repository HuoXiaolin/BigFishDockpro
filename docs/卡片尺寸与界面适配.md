# 卡片尺寸与设置窗口适配

## 桌面卡片和便签

- 设置“桌面收纳 → 卡片缩放 → 尺寸与文字”，或卡片/便签菜单“尺寸与文字”。
- 文字大小应用到所有现有、新建和恢复的卡片、便签，手动改变宽高不会另存不同字号。
- 默认宽高只用于新卡片。独立卡片和便签可拖动右下角改变大小，分别记忆；合并页面共用宽高，切换分组不按内容改变高度。
- 保存字号不改变现有宽高。位置、颜色、内容、锁定和收起状态分别保留；缩放和换屏继续使用屏幕参照。
- 设置操作按钮按用途并排，避免单个操作铺满整行；长说明移到关联控件的提示中。

## 设置窗口

右上角“窗口大小”提供：

| 模式 | 行为 |
| --- | --- |
| 自动适配 | 按当前屏幕可用界面区域选择档位；分辨率高时使用更大字号与控件 |
| 小 | 560×448，紧凑布局 |
| 中 | 800×640，标准布局 |
| 大 | 1200×960，更大字号、控件、色块和间距 |
| 手动调整 | 拖动右下角后进入，保存当前宽高和此前字号档位 |

以上宽高为系统缩放后的界面尺寸，屏幕不足时限制在可用区域内。自动档在可用宽至少3000或高至少1700时选择大；至少1550×850选择中；其余选择小。手动尺寸保存后，在小屏重新打开时会限制显示范围，返回可容纳的屏幕再按已存尺寸恢复。

点击“保存设置”记录当前选择；关闭放弃未保存的模式和手动尺寸。切换主题或重复打开不累计放大。卡片尺寸设置弹窗跟随已保存的界面档位，右键菜单继续保持紧凑。
