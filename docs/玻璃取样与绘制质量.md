# 玻璃取样与绘制质量

灵动胶囊、桌面卡片、闪念胶囊和桌面频谱各有「玻璃背景」设置。置顶时按所选模式显示，默认选中「动态透明」，以圆角内的半透明材质透出实际窗口及桌面。置底时使用所在屏幕的壁纸，恢复置顶后继续使用原先的选择。模糊强度用于壁纸。频谱仅在粒子、光环或柱形等已绘制的像素内合成壁纸，周围空白保持透明。 [Windows 分层窗口](https://learn.microsoft.com/windows/win32/winmsg/window-features#layered-windows)

桌面卡片支持置顶和置底，层级应用到全部卡片。在卡片、闪念或频谱的右键菜单可选「可交互」「始终穿透」或「置顶时穿透应用窗口」。第三种模式在组件覆盖应用窗口时把点击交给下方应用，桌面上的部分仍可交互。

便签、时钟、日历和 Dock 使用同一套壁纸取样与平滑模糊通道。壁纸来自 Windows 的壁纸配置。

壁纸按像素预算解码，共享缓存最多一张、约 1 MiB（262,144 像素）。超过预算时等比例取样，保留原始尺寸和屏幕坐标。空闲清理缓存和退出时释放共享解码图像。大于 128K 像素且需要较强模糊的背景保留半尺寸纹理，DPR 同比例调整。文字、图标和边框按原生分辨率单独绘制。

模糊在取样更新时离屏准备，保持输出物理像素尺寸与设备缩放比，使用 Qt 质量优先的模糊，不在组件每帧绘制中运行图形特效。边缘先延展以避免透明或黑色接缝；调整模糊强度仍会改变柔化程度，不等于将模糊背景变成锐利原图。

圆角填充与描边分开裁剪，避免描边外侧被切掉。圆球与胶囊分类图标按最终尺寸和实际DPR从矢量重新绘制，不再放大标题栏小图标。时钟、日历和便签使用平滑贴图设置。

验证包括2048像素单像素条纹、共享缓存预算、100%/125%/150%/200%离屏渲染和模糊边缘检查。真实显示器切换与不同显卡仍以实际设备表现为准。

参考：[Qt 模糊效果](https://doc.qt.io/archives/qt-5.15/qgraphicsblureffect.html)、[Qt 图像读取](https://doc.qt.io/archives/qt-5.15/qimagereader.html)。
