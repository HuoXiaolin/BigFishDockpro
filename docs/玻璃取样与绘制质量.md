# 玻璃取样与绘制质量

桌面卡片（含收起方条、胶囊与圆球）、便签、时钟、日历和 Dock 共用壁纸取样与平滑模糊通道。取样始终来自 Windows 壁纸配置，不采集前台软件，不启用实时玻璃。

壁纸按像素预算解码，共享缓存最多一张、约 1 MiB（262,144 像素），不会每张卡片保留整幅壁纸。超过预算时等比例取样，保留原始尺寸和屏幕坐标，不修改桌面壁纸文件。进入精简模式、空闲内存维护和退出时清空共享解码缓存。大于 128K 像素且需要较强模糊的背景保留半尺寸纹理，DPR 同比例调整，覆盖的逻辑范围不变；文字、图标和边框仍按原生分辨率单独绘制。

模糊在取样更新时离屏准备，保持输出物理像素尺寸与设备缩放比，使用 Qt 质量优先的模糊，不在组件每帧绘制中运行图形特效。边缘先延展以避免透明或黑色接缝；调整模糊强度仍会改变柔化程度，不等于将模糊背景变成锐利原图。

圆角填充与描边分开裁剪，避免描边外侧被切掉。圆球与胶囊分类图标按最终尺寸和实际DPR从矢量重新绘制，不再放大标题栏小图标。时钟、日历和便签使用平滑贴图设置。

验证包括2048像素单像素条纹、共享缓存预算、100%/125%/150%/200%离屏渲染和模糊边缘检查。真实显示器切换与不同显卡仍以实际设备表现为准。

参考：[Qt 模糊效果](https://doc.qt.io/archives/qt-5.15/qgraphicsblureffect.html)、[Qt 图像读取](https://doc.qt.io/archives/qt-5.15/qimagereader.html)。
