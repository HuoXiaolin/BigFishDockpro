# 运行模式与更新

## 精简模式

默认启用自动精简，启动后或关闭设置后启动一次 60 秒计时。打开设置时退出精简并停止倒计时；再次关闭设置重新计时。可在设置关闭自动精简，也可通过托盘手动切换。

精简模式保留 Qt 主循环、基本 Dock、应用启动、拖入/排序、托盘、自启动配置与静态圆角；关闭模糊抓取，释放模糊缓存和可重建图标缓存，暂停运行进程扫描、位置轮询、全屏检测，将桌面面板收为方条或胶囊并释放背景缓存，保留目录变动分类通知，并把本进程调到低于普通优先级。静态圆角没有额外轮询。后台任务的停止不修改用户已保存的外观设置。

这表示减少后台工作，不承诺特定内存值、零 CPU 或所有环境的绝对最低占用；Python/Qt 必需运行库仍保留在进程内。没有通过强制 GC、压工作集或最小化伪装资源降低。

进入精简后主动打开面板或批量管理会恢复完整运行，之后重新计时。打开设置则一直保持完整模式，直到设置关闭。仅显示/隐藏基础 Dock 不必退出精简。

## 游戏与全屏

手动游戏模式隐藏 Dock、面板和圆角；退出后只恢复原先可见的窗口，原先隐藏的保持隐藏。自动全屏检测使用 Windows 前台窗口和所在显示器矩形，每 1.5 秒一次；排除本进程、桌面、任务栏及普通带标题栏最大化窗口。它只控制 Dock 与面板，不隐藏圆角；退出全屏恢复之前的显示状态。全屏检测无法区分游戏、浏览器与视频，游戏时从托盘启用游戏模式以隐藏圆角，不冒充已经实现自动识别游戏。

精简模式优先于全屏检测：暂停该轮询并释放自动游戏状态，避免检测停止后 Dock 一直隐藏；手动游戏设置仍保留。打开设置暂时解除游戏遮蔽，方便修改。特定游戏、真全屏、受保护内容和多显示器组合需要实际电脑验证。

## 屏幕圆角

每块显示器四个小型黑色鼠标穿透遮罩，半径可调。它改变屏幕角落的视觉效果，不修改系统窗口、任务栏或显示器设置，也不改变窗口本身的形状。默认关闭，可在设置启用；桌面、普通窗口、最大化窗口、普通全屏应用、设置页与精简模式均保留，仅手动游戏模式隐藏。关闭圆角开关或退出软件时释放。布局和半径不变时复用遮罩，不增加常驻轮询。

## 自启动

保留 HKCU Run 用户级自启动，新增 `--autostart` 参数用于区分登录启动与手动启动。登录启动可延迟 0–300 秒，并静默进入托盘；已启用的桌面收纳面板仍按布局显示，不弹设置窗口。手动启动不延迟。低/普通/较高选项调整本应用的进程优先级，其中“较高”使用 ABOVE_NORMAL，不是实时或系统高优先级；这不保证 Windows 登录启动顺序。

## 更新源协议

设置中可启用启动检查，并选择使用系统/环境代理或直连。默认没有更新源，也不启用联网检查；没有清单地址时不发起网络请求。

源必须是自己项目维护的 HTTPS JSON 清单，结构见 `update_manifest.example.json`。要求 `product_id` 为 `BigFishDockpro`，版本为三段数字，下载页面链接为 HTTPS。清单有大小上限、超时和错误说明；不会使用上游或其他项目的版本代替。

目前实现检查与打开新版本下载页面，由用户决定下载安装，不静默替换正在运行的程序。没有真实更新源时只验证解析、版本比较、代理选择和失败路径，不声称完成线上更新验收。

任务栏底部圆角：遮罩固定在完整屏幕边缘，并用 Windows 窗口事件监听前台切换、任务栏显示/位置与置顶层级变化，合并为一次短延迟的置顶恢复。只调整本软件遮罩，不修改任务栏属性或窗口尺寸，不激活遮罩、不拦截鼠标。精简模式保留这些事件通知，空闲时没有周期计时器；关闭圆角或游戏模式隐藏时注销。实现依据 [Microsoft SetWinEventHook](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-setwineventhook)。

## 自启动路径检测与修复

“设置 → 运行方式”显示已登记路径和当前运行路径，支持检测启动项缺失、登记文件不存在、路径指向其他位置及 --autostart 参数错误。源代码运行时同时检查解释器和脚本路径。点击“修复并启用自启动”立即更新本应用的 HKCU Run 值并保存开启状态，其他尚未保存的设置不提交；写入后回读校验，保存失败恢复原值。测试只使用独立临时注册表键，不写入真实 Run 项。这里只检查本应用登记的路径与参数，不冒充已经执行 Windows 重新登录验收。

## 缓存与内存

批量管理仅加载当前可见行和少量前后预取图标，离屏图标不一直留在列表中。关闭页面后短期保留扫描结果，避免频繁重扫；进入精简模式释放隐藏列表与结果，再打开时重新扫描。已经收起的面板释放图标列表，展开时从已保存记录恢复，布局和收纳数据不变。图标 LRU 限制 128 项、6 MiB 估算像素预算，Qt 公共图片缓存上限 4 MiB，精简时清空可重建缓存。

在独立 Windows 桌面生成 500 个临时应用图标，使用 GetProcessMemoryInfo 测量本进程私有字节：优化前批量打开约 62.7 MiB，精简后仍约 62.7 MiB；优化后分别约 31.9 和 31.0 MiB。数据来自同机同负载各一次测试，存在分配器和系统波动；不是实际用户桌面、不同机器或最低内存承诺。没有调用 EmptyWorkingSet、SetProcessWorkingSetSize 或强制 GC。基线与优化过程位于 artifacts/memory-before、memory-after-lazy。
