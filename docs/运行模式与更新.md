# 运行模式与更新

## 闲置资源回收

常规运行会检查空闲状态，自动释放隐藏的收纳窗口、资源页和已关闭的设置。可见组件保留外观、尺寸、展开状态和表情跟随。隐藏页面再次打开时按需创建，恢复城市和筛选等选择。

拖动或使用菜单、对话框时延后回收。达到内存阈值后再清理可重建的图片缓存并归还未用堆页。光环动画、实时毛玻璃和表情互动各有自己的开关。

## 组件暂停

「启动与运行 → 组件暂停」和托盘右键的「组件暂停」菜单均提供两项开关。手动开启「暂停桌面组件」会隐藏 Dock、收纳、便签、时钟、资源胶囊、任务栏监控和屏幕圆角等，随之暂停相关采样。关闭时按保存的显隐偏好恢复。

「全屏自动暂停」默认关闭。开启后每 1.5 秒根据前台窗口是否覆盖所在显示器来判断，普通最大化窗口会排除，浏览器或视频全屏也可触发。自动暂停时保留圆角和已置顶的任务栏监控，退出全屏会自动恢复。手动暂停开启时，关闭自动暂停后仍保持手动状态。

## 屏幕圆角

每块显示器四个小型黑色鼠标穿透遮罩，半径可调。手动暂停桌面组件时隐藏圆角，自动全屏暂停时仍显示。关闭圆角开关或退出软件时释放。布局和半径不变时复用遮罩。

## 自启动

`--autostart` 参数用于区分登录启动与手动启动。登录启动可延迟 0–300 秒，并恢复上次保存的 Dock、面板和暂停偏好。手动启动直接进入界面。低、普通、较高三档调整本应用的进程优先级，其中「较高」使用 ABOVE_NORMAL。

## 更新源协议

设置中可启用启动检查，并选择使用系统/环境代理或直连。默认没有更新源，也不启用联网检查；没有清单地址时不发起网络请求。

源必须是自己项目维护的 HTTPS JSON 清单，结构见 `update_manifest.example.json`。要求 `product_id` 为 `BigFishDockpro`，版本为三段数字，下载页面链接为 HTTPS。清单有大小上限、超时和错误说明；不会使用上游或其他项目的版本代替。

目前实现检查与打开新版本下载页面，由用户决定下载安装，不静默替换正在运行的程序。没有真实更新源时只验证解析、版本比较、代理选择和失败路径，不声称完成线上更新验收。

任务栏底部圆角用 Windows 窗口事件监听前台切换、任务栏显示、位置与置顶层级变化，合并为一次短延迟的置顶恢复。关闭圆角或手动暂停桌面组件时注销监听。 [Microsoft SetWinEventHook](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-setwineventhook)

## 自启动路径检测与修复

“设置 → 运行方式”显示已登记路径和当前运行路径，支持检测启动项缺失、登记文件不存在、路径指向其他位置及 --autostart 参数错误。源代码运行时同时检查解释器和脚本路径。点击“修复并启用自启动”立即更新本应用的 HKCU Run 值并保存开启状态，其他尚未保存的设置不提交；写入后回读校验，保存失败恢复原值。测试只使用独立临时注册表键，不写入真实 Run 项。这里只检查本应用登记的路径与参数，不冒充已经执行 Windows 重新登录验收。

## 缓存与内存

批量管理加载当前可见行和少量预取图标。关闭页面后短期保留扫描结果，空闲回收时释放隐藏列表，再打开时重新扫描。图标 LRU 限制 128 项、6 MiB 估算像素预算，Qt 公共图片缓存上限 1.5 MiB。

在独立 Windows 桌面生成 500 个临时应用图标，使用 GetProcessMemoryInfo 测量本进程私有字节：优化前批量打开约 62.7 MiB，精简后仍约 62.7 MiB；优化后分别约 31.9 和 31.0 MiB。数据来自同机同负载各一次测试，存在分配器和系统波动；不是实际用户桌面、不同机器或最低内存承诺。没有调用 EmptyWorkingSet、SetProcessWorkingSetSize 或强制 GC。基线与优化过程位于 artifacts/memory-before、memory-after-lazy。

保存 Dock 与面板显隐、托盘显隐、Dock 页码、卡片收起与尺寸，以及合并卡片的当前页面。暂停状态与各组件的显隐偏好分别记录。升级时忽略旧精简模式字段，按已有布局和组件开关恢复。

表情的鼠标跟随和按压互动由资源胶囊与桌面收纳卡片共用。隐藏后停止表情检测和绘制。主进程采用受系统支持的 Segment Heap，实测范围见「资源与内存优化验证」。
