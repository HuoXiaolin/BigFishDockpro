# 原生卡片配置

在「设置 → 桌面组件 → 原生卡片编辑器」点击「复制开发提示词」，写上卡片需求。把生成的 JSON 粘贴到「导入 JSON」，再保存显示。编辑器的「排版与配图」页也能直接选文件、改字号和颜色。

## 每日一言

```json
{
  "title": "每日一言",
  "width": 420,
  "style": "solid",
  "arrangement": "image_right",
  "header_date": true,
  "fonts": {"title": 22, "body": 18},
  "colors": {"surface": "#EDF5F9", "text": "#193747", "accent": "#5295BB"},
  "image": {"path": "C:/Users/Public/Pictures/cover.png", "fit": "contain", "height": 112},
  "data_file": "quote.json",
  "rows": [{"kind": "data", "label": "", "value": "quote"}]
}
```

将图片路径改成自己的文件。标准 JSON 可用正斜杠，例如 `D:/图片/配图.png`。编辑器也支持在图片路径与本地数据路径中粘贴资源管理器复制的 Windows 盘符路径。相对路径从应用配置目录解析。将 `quote.json` 放在同一配置目录中，内容可由自己的脚本或程序写入。卡片显示时，每分钟检查一次文件是否有更新。配置只保存路径，换电脑时需要同时带走图片和数据文件。

```json
{"quote": "把大目标拆小。\n今天先迈一步。"}
```

## 组合工具

每张卡片可有一个 `tool` 和最多六条 `rows`，也可以只显示工具。内置模板可以作为生成新卡片的起点。

| `tool.kind` | 可配置内容 |
| --- | --- |
| `search` | `engine` 选必应、百度、Google 或 DuckDuckGo。用 `url` 配置自己的 HTTPS 搜索网址，在查询参数中放入 `{query}` |
| `pomodoro` | `minutes` 与 `break_minutes` 分别设置专注和休息时长 |
| `history` | `lang` 选择中文或英文，`limit` 设置 1–5 条。显示来源语言 |
| `rates` | `from`、`to` 和 `amount` 设置默认换算。显示欧洲央行参考汇率的发布日期 |
| `convert` | `units` 中为每个单位设置 `name`、`factor` 和可选 `offset`，用于长度、重量或温度换算 |
| `feed` | `url` 指定 HTTPS JSON，`interval` 设置 15–1440 分钟。`remote` 行用 `value` 绑定字段 |

例如把 `tool` 设为 `{"kind":"feed","url":"https://example.org/daily/{date}.json","interval":1440}`，再添加 `{"kind":"remote","label":"今日内容","value":"items.0.title"}`。网址可使用 `{date}`、`{month}` 或 `{day}`。卡片会读取日期对应的公开 JSON，提取 `items` 中第一项的标题。把示例地址换成自己的数据服务即可。

卡片使用原生控件及 JSON 数据绑定。可通过这些字段组合卡片，后台会合并同一来源的读取，并在卡片隐藏后停止刷新。
