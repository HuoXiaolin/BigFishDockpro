# 隐藏资源释放

- 可见组件保留材质、字体、背景和展开状态。隐藏 Dock 释放模糊背景、倒影、缩放缓存；重新显示前重建。
- 隐藏时钟、日历和便签释放背景图，停止对应的刷新或计时。
- 隐藏及非活动合并卡片释放图标、缩略图和列表对象；保留搜索、选择与滚动位置，在首次重新显示前恢复。
- 主设置、应用管理、便签管理及快捷设置关闭闲置 60 秒后回收窗口。使用单次定时器，不增加周期性全窗口扫描；重新打开按已保存配置重建。
- 隐藏便签不在启动时提前创建编辑器。已存在的隐藏编辑器闲置 60 秒后，确认内容保存成功且没有可见便签设置或未提交待办输入，再回收。
- 保存失败、未提交的待办输入以及仍在运行的应用扫描会暂缓回收；最小化仍可见的编辑窗口不会被回收。

便签正文、格式、待办和已保存位置保留；编辑器的撤销历史不跨编辑器回收保留。关闭设置时，未保存的设置仍按原规则放弃。

验证采用独立 Windows 桌面、临时配置和合成文件，核对真实 Qt 定时到期回调、销毁后的重建、保存失败和线程保护。测试缩短到期时间，正式策略保留 60000 ms；不把这些短时检查当作长期真实桌面内存测量。
