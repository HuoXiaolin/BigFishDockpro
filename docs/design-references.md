# 卡片设计参考

桌面卡片的浅色渐变边框和点击翻面方向参考以下 Uiverse 作品，以 PyQt 绘制和交互重新实现；配色取软件主题色，文件卡片保持稳定，不使用悬停翻面。

- Cobp: https://uiverse.io/Cobp/popular-gecko-2
- joe-watson-sbf: https://uiverse.io/joe-watson-sbf/little-goat-24
